# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately using GitHub's
"Report a vulnerability" button (Security tab → Advisories) on this repository.

Include a description, affected version/commit, and reproduction steps. You can
expect an acknowledgement within 7 days. Please allow reasonable time for a fix
before public disclosure.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
